# VidGrab

Download videos from YouTube, Instagram, Facebook, X, TikTok and [1000+ sites](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md), in the quality and format you pick (MP4, MKV, WebM, MP3, M4A, WAV).

Works in Chrome, Brave, Edge and Vivaldi on Windows, macOS and Linux.

## Install

**1. Download** this repo (**Code → Download ZIP**) and unzip it.

**2. Run the installer** in the unzipped folder:

| OS | Do this |
|---|---|
| Windows | Double-click `install_windows.bat` (if warned: **More info → Run anyway**) |
| macOS | Install [Homebrew](https://brew.sh) first, then in Terminal: `bash install_mac.sh` |
| Linux | `bash install_linux.sh` |

**3. Load the extension** in your browser:

1. Open `chrome://extensions` (or `brave://extensions`, `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and paste the folder path the installer copied to your clipboard:
   - Windows: paste into the address bar of the folder picker
   - macOS: press `Cmd + Shift + G`, then paste
   - Linux: press `Ctrl + L`, then paste
4. Restart the browser.

Done. You can delete the downloaded folder now.

## Use

Hover a video and click **⬇ Download**, choose quality and format, then click **Download**.
Files go to your **Downloads** folder.

If the video is part of a playlist, click **Download all** to get the whole playlist.

## Something stopped working?

Click **Update yt-dlp** at the bottom of the VidGrab panel.
